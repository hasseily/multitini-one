# IIgs MMU: physical ROM03 reference

Physical ROM03 observations take precedence over emulator behavior. The
core preserves the measured ROM01 text-page-2 difference when ROM01 is selected.

| Area | Implemented behavior |
| --- | --- |
| Extended shadow | SPEED.4 enables text and graphics shadowing in installed fast banks, using the resolved main/aux bank. |
| Extended aux and I/O | SPEED.4 enables aux selection and mapped I/O in those banks. Mapped Cxxx stores do not write backing RAM. |
| Aux HGR | E1 receives HGR1 when SHADOW.3 is clear, or both SHADOW.4 and SHADOW.1 are clear. HGR2 substitutes bit 2 for bit 1. |
| Text page 2 | SHADOW.5 controls ROM03 shadowing. ROM01 does not shadow this page. C036.6 does not disable ROM03 capability. |
| Language card | E0/E1 overlay ROM and obey the shared write-enable latch. SHADOW.6 inhibits fast low-bank I/O/LC mapping. |
| IOLC RAM | With low-bank IOLC inhibited, C800 exposes LC bank 2 and D800 exposes LC bank 1. |
| Registers | C029 reads `v & E1`; C02D reads `v & F6`; C035, C036 and C068 read `v`. |
| Slot 3 | C00A/B changes SLOTC3ROM independently of C02D. Internal C3 reads and writes acquire internal C800. Other Cn accesses preserve that latch. |
| CFFF | Reads and writes release internal C800. With INTCXROM clear, the CFFF read uses the floating bus. INTCXROM continues to select internal ROM. |
| Absent memory | Sampled banks 80/81/82/DF return the bank byte and discard stores. ROM01 FC/FD return FC/FD; ROM03 selects ROM. |
| Unowned C800 | Uses the existing video/last-CPU-data floating bus. |

All numbers above are hexadecimal. Reset defaults are unchanged by this patch;
the capture records launch state, not cold-reset measurements.

## Hardware fixture

`hdl/sim/fixtures/iigs_mmu_rom03.json` contains 45,824 main observations plus
supplemental memory, I/O, text-page-2 and C800 selection observations. It contains
no Apple ROM bytes. Variable floating-bus bytes are excluded; C800 retains only
selection classifications. Two coincidentally zero CFFF samples are classified
with the remaining floating samples, rather than treated as proof of ROM selection.

Source packet SHA-256:
`229b1ff3000003086ab63ca9abe33cd8f1dafee29acd611ac163f2f5f06d923c`.
Packet CRC32: `9fa6eb7c`. Flags, anomalies and skipped cases: zero.

Tester: ROM03, System 6.0.2 / GS/OS 4.0.2, CFFA 3k, RAM2GS II 8MB,
shift boot, no /RAM5. The original photograph and full decoded packet remain
in the separate verified-results handoff. The regression needs neither artifact.

The state fixture uses production I/O state and MMU selects. It classifies
backing-memory marker effects; it does not execute the native probe or model
memory timing. The adapter regression executes synthetic 65816 programs with
synthetic ROMs at stock and maximum speed.

Port changes are generated by `scripts/port_apple_iigs_core.py`. The imported
MiSTer source remains pinned to `9adbba8622f378253765b7d438b6cbcc4d03fc57`.

Matching the captured cases does not establish complete ASIC equivalence.
Floating-bus timing, unmeasured mappings, a rebuilt FPGA image and physical
Multitini acceptance require separate validation. The slot-7 SmartPort firmware
and its C7 release trampoline remain board extensions.
