## Product boundary

The Multitini build uses the Game Boy/Game Boy Color machine, mapper, video,
audio, timer, DMA, and T80 dependencies. It does not import the MiSTer platform
top, Intel PLL/SDRAM wrappers, releases, borders, palettes, screenshots, binary
boot ROMs, or game cartridges.

`third_party/gameboy/import_manifest.json` is the exact allowlist. The selected
first adapter supports:

- GB and GBC cartridges from 32 KiB through 8 MiB;
- one eight-button gamepad;
- raw RGB555 video expanded to RGB888;
- stereo audio sampled onto the common 48 kHz event stream; and
- the open SameBoy-derived CGB bootstrap, with an optional exact-size run-time
  override.

SGB, MegaDuck, camera UI, link cable, cheats, rewind, savestates, borders, and
persistent RTC/save handling are outside the first adapter. Mapper logic stays
close to upstream even where those optional services are disabled.

## Local compatibility ports

The exact upstream `rtl/gb.v` and `rtl/cart.v` files remain imported and locked
as references. The product manifest builds deterministic ports generated by
`scripts/port_gameboy_core.py`:

- `hdl/core/gameboy/ports/gb.v` selects the generated open bootstrap hex and
  moves declarations before use for strict tools;
- `hdl/core/gameboy/ports/cart.v` moves mapper-facing declarations before use;
  and
- `hdl/core/gameboy/ports/dpram.sv` replaces Intel dual-port RAM primitives.

The product bootstrap hex is generated from the pinned MIF by
`scripts/generate_gameboy_bootrom.py`. Both artifacts are allowlisted by the
repository content check and covered by the upstream MIT notice and source.

## Memory path

The cartridge loader writes aligned 64-bit lines into the common memory
request/response service. A one-line core-side cache stalls Game Boy clock
enables on a miss or external cartridge-RAM write. The board wrapper contains
a control-to-machine CDC bridge and a prepared Appletini PSRAM PHY path.

`ENABLE_GBC_PSRAM` defaults to zero, so the physical PSRAM pins remain inactive.
The opt-in branch is source preparation only until Vivado confirms RAM
inference, CDC constraints, I/O delay resources, timing, and hardware data.
